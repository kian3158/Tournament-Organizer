# Tournament Organizer

A full-stack tournament organizer focused on esports and LAN-style competitions.

## Stack

- Backend: FastAPI, PostgreSQL, SQLAlchemy, Alembic
- Frontend: React + TypeScript + TailwindCSS
- Tools: Ruff, Black, Pytest, ESLint, Prettier
